# 万卷 · 视觉提案（选型评审件）

为「万卷——中小学文学知识库」准备的三套风格完全不同的界面设计提案，供项目所有者选择最终视觉方向。

## 查看方式

- 直接双击任意 HTML 文件，在浏览器中打开即可（单文件、内联 CSS、系统字体栈、无任何外部依赖，离线可用）。
- 建议桌面浏览器查看，内容宽度按 1200px 设计；窗口缩放可自适应，不破版。
- 每个文件包含四帧样张：**首页 mock、词条详情 mock（统一用《静夜思》真实内容）、设计令牌卡、定位说明卡**。

## 评审建议

逐套打开后，建议重点对比：

1. **首页信息层级**：slogan、搜索、四件套、学段入口的视觉权重分配是否合意；
2. **词条阅读体验**：《静夜思》原文区的呈现（竖排诗笺 / 宽字距排印 / 渐变诗卡）哪套更贴近日常使用；
3. **令牌可扩展性**：三套 CSS 变量体系（见各文件「设计令牌」卡）哪套更利于后续页面（图谱、词云、统计、复习）批量铺开。

选定后，可从对应文件的令牌卡直接抽取 CSS 变量与字体栈，作为 VitePress 主题定制的起点。
