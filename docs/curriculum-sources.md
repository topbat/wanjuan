> 权威来源、双源交叉核对过程与结论。数据准确性是本项目的第一要求，
> 任何篇名/作者与官方文件不符都不可接受。

## 3. 交叉核对方法与结果

1. **小学 75 篇**：官方扫描件逐条转录 ↔ 新浪全文清单逐条比对，
   1～75 条篇名（含首句括注）、作者、顺序**全部一致**；
   中段（第 10～27、46～65 条）另与整理版比对，除 §5 所列整理版自身编辑性偏差外一致。
2. **初中 60 篇（段）**：官方扫描件逐条转录 ↔ 新浪全文清单逐条比对，
   1～60 条**全部一致**（含第 6 条篇名作《木兰辞》、第 41 条《论语》十二章的十二章目）。
3. **高中 72 篇**：官方 PDF 文本层直接提取（无 OCR 误差） ↔ 整理版高中目录/正文比对，
   文言文 32 篇（必修 10＋选择性必修 10＋选修 12，其中"古代文论选段"含 6 则）、
   诗词曲 40 首的篇名、作者、顺序**全部一致**（含《贺新郎》作者刘克庄、首句"国脉微如缕"）。
4. **数量自检**：`python public/curriculum/verify.py`（期望值 75/60/72，全部通过）。

## 4. 重要说明：初中是 60 篇（段），不是 61 篇

**2022 年版课标原文**（附录1 引言，官方 PDF 印刷页 58）：

> "义务教育阶段要求学生背诵古今优秀诗文……这里仅推荐古诗文135篇（段）。
> 其中1～6年级75篇，7～9年级**60篇（段）**。"

证据链：

1. 官方扫描件引言明文"7～9年级60篇（段）"，且 75＋60＝135，与"仅推荐古诗文135篇（段）"自洽；
2. 官方扫描件分节标题为"7～9年级（60篇/段）"（印刷页 61，经 3 倍放大复核）；
3. 官方表格编号从第 1 条《关雎》连续编排至第 60 条《湖心亭看雪》，下一页即附录2，无第 61 条；
4. 新浪教育 2022-05-06 全文转载清单：7～9年级共 60 条，逐条与官方一致；
5. 搜狐 2022-05 同期报道亦引"1～6年级75篇，7～9年级60篇（段）"；
6. 湖南女子学院整理版 PDF 引言同样转录"7~9年级60篇(段)"。

**"61 篇（段）"的来历**：《义务教育语文课程标准（2011年版）》附录1 为
"1～6年级75篇，7～9年级61篇（段）"（75＋61＝136）。2022 年版修订时初中减为 60 篇（段）。
大量网络资料沿用 2011 年版旧数字，与 2022 年版官方文件不符。

**本项目处理**：`junior.json` 以 2022 年版官方文件为准，收录 60 条，
`verified_count = 60`，并在文件内 `count_note` 字段记录本差异。
README 中"小学 75 篇＋初中 61 篇＋高中 72 篇"的表述沿用了旧数字，以本文件为准（合计 207 篇）。

## 6. 字段说明

- `grade`：三份文件的课标原文均**未按年级/模块分组**给出具体年级（高中仅在文言文部分
  按必修/选择性必修/选修分栏，已记入各条 `note`），故 `grade` 全部为 `null`；
- `form`：体裁按公认文学常识标注（词/曲/文言文/五言绝句等），个别争议较大者从通说；
- `note`：课标原表的首句括注、节选范围、所据篇目，及"统编教材题作××"的对照信息。

## 7. 复核方式

```bash
cd public/curriculum
python verify.py
# [校验] 小学（1～6年级）篇目 75/75 ✓
# [校验] 初中（7～9年级）篇目 60/60 ✓
# [校验] 高中篇目 72/72 ✓
```

校验内容包括：条数恰好等于期望值、编号连续、必填字段齐全、篇名非空、
`recitation` 全为 true、完全重复条目检测、来源 URL ≥ 2 个。
