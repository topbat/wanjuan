## 复跑方式

```bash
node scripts/tag-genre.mjs            # 只标注仍为「待归类」的作品（幂等）
node scripts/tag-genre.mjs --force    # 重新评估本工具曾标注的作品（人工标注不动）
node scripts/tag-genre.mjs --dry-run  # 只统计并生成报告，不写回 md
```

校对闭环：打开站点 `/explore/genre-review`，逐条确认/改判并导出 Markdown，再按 `srcPath` 回写 frontmatter。
