# 万卷 · 列表与筛选交互规范（v1）

> 适用于成语库、名句库、作品库等「数据会持续增长」的浏览页。
> 目标：**在几百到几千条规模下仍然易读、易筛、易回退**，并保持三主题视觉一致。

## 1. 调研结论（2025 共识）

| 决策点 | 结论 | 依据 |
|---|---|---|
| 分页 vs 无限滚动 | 内容型/目标型浏览用**分页或「加载更多」**，不用无限滚动 | NN/g「无限滚动适合发现，不适合查找」；Baymard 多次测试中分页/Load More 的任务完成率均高于无限滚动；Etsy A/B 把无限滚动改回分页后互动与购买率上升 |
| 筛选交互 | **带计数的胶囊按钮**（chip）+ 已选条件行 + 「清除全部」 | 计数让用户预判结果数量；零结果选项置灰；已选行是"为什么看到这些"的单一事实源 |
| 状态存储 | **URL 承载筛选与页码**（`?q=&field=a,b&page=2`） | 可分享、刷新不丢、后退正确；用 `replaceState` 更新 chip 切换 |
| 多选语义 | 同一维度内 **OR**，跨维度 **AND** | 行业通行 |
| 移动端 | 筛选折叠为一行「筛选 · N」，展开为底部面板；结果数用 `aria-live` 播报 | 避免筛选时结果在手指下方跳动 |
| 空/加载态 | 骨架屏占位列表区域；零结果给"清除某条件"的建议 | 状态是功能的一部分 |
| 长选项表 | 单维度选项 > 15 个时，提供"维度内搜索" | 减少滚动 |

## 2. 万卷落地约定

### 2.1 视觉：胶囊按钮（Chip）
- 默认态：`--wj-card` 底、`--wj-line` 边、`--wj-ink-2` 字
- 选中态：`--wj-accent` 底、白字、轻微上浮
- 计数：紧随标签，`--wj-ink-3`，字号 12px；选中时白字 70% 透明度
- 零计数：`opacity: .38` 且 `pointer-events: none`
- 圆角：`999px`（三主题通用，宣纸主题允许 2px 近直角由令牌覆盖）
- 高度 ≥ 32px，移动端 ≥ 40px

### 2.2 结构
```
[ 搜索框（汉字/全拼/首字母） ]
[ 维度A: chip chip chip ]      ← 一行一组，可横向滚动
[ 维度B: chip chip chip ]
[ 已选：A=x ×  B=y ×   清除全部 ]   [ 共 328 条 · 按热度 ▾ ]
[ 卡片网格 / 表格 ]
[ 分页：‹ 1 2 3 … ›   每页 24 ▾ ]
```

### 2.3 卡片
- 网格：`repeat(auto-fill, minmax(260px, 1fr))`，间距 14px
- 卡内：标题（主）、副行（拼音/出处/作者）、正文摘要（最多 3 行截断）、底部分类胶囊
- 悬停：`translateY(-3px)` + 阴影加深；`prefers-reduced-motion` 下取消
- 入场：仅首屏卡片做 40ms 阶梯淡入，切页不重放

### 2.4 可用性
- 所有 chip 用 `<button>`，`aria-pressed` 表示选中
- 结果计数容器 `aria-live="polite"`
- 键盘：Tab 可达、Enter/Space 触发；清除按钮有 `aria-label`
- 深链接：`?q=...&semantic=勤奋,诚信&page=2` 直接可打开

## 3. 复用组件

| 组件 | 路径 | 职责 |
|---|---|---|
| `WjFilterBar` | `site/.vitepress/theme/components/WjFilterBar.vue` | 渲染多维胶囊筛选（含计数、零结果置灰、已选行、清除全部） |
| `WjPager` | `site/.vitepress/theme/components/WjPager.vue` | 分页器（页码 + 每页条数 + 结果计数播报） |
| `useUrlState` | `site/.vitepress/theme/composables/useUrlState.ts` | 读写 URL 查询参数（多值用逗号分隔） |

> 新页面**必须**复用这三个件，不要各自重写筛选逻辑，避免交互不一致与后续维护成本。
