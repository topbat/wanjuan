## 三、体验原则（供后续页面遵守）

1. **内容优先**：首屏必须见到内容，控件让位；控件可折叠、可吸顶。
2. **一屏一个决策**：同一页面不要同时要求"选主题、选朝代、选学段、翻页"四件事；默认值和智能推荐先行。
3. **状态可恢复**：筛选、视图、页码写进 URL；返回时滚动位置尽量保留。
4. **层级靠字号与留白，不靠颜色堆叠**：一套页面最多一个强调色。
5. **动效服务于定位**：只做"出现/离开/聚焦"的短动效（≤220ms），不做装饰性循环动画。
6. **空态要给下一步**：零结果时给出「清除某条件」或推荐内容，而不是一句"暂无数据"。
