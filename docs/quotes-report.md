## 11. 已知局限

- 名句正文严格取自本库 `content/poems/` 的「## 原文」块；部分课标篇目在导入时存在节选、异文或 OCR 讹字（如 `春风自绿江南岸`、`沈舟侧畔`、`江枫渔父`、`忽然一夜春风来`、`江月年年秖相似`），本脚本一律以库内原文为准，不按通行本改写。
- 语境为「包含名句的整句 + 必要的下一句」，散文长句可能比诗体两句更长；最长语境约 54 字。
- 本库未收录的常见名句不会凭记忆生成，统一进入第 5 节丢弃清单；校验通过但受 140 条上限约束的 16 条见第 7 节备选清单。
- 名句浏览器页的拼音搜索在客户端用 `pinyin-pro` 计算，不新增构建索引字段；构建会因此出现一条 >500KB chunk 提示。
- 为让「展开语境」在开发与静态构建下都即时可用，脚本额外生成 `site/public/indexes/quotes-detail.json`（语境/场景副索引），不修改 `build-index.mjs` 的六件产物。
- 按文件所有权要求未修改 `site/.vitepress/config.mts` 与 `theme/index.ts`：页面文件为 `site/quotes/index.md`，当前构建路由为 **`/site/quotes/`**；若需挂到 `/quotes/` 并在顶栏/侧栏露出，需由 config 负责人补充 rewrite（`'site/quotes/:splat*': 'quotes/:splat*'`）与导航入口。
- 既有名句「铁马冰河入梦来」因本库未收录《十一月四日风雨大作》而归档至 `content/quotes/.discarded/`，未计入 140 条。
