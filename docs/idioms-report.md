## 8. 已知局限

1. **页面路由为 `/site/idioms/`，不是 `/idioms/`**：`site/.vitepress/config.mts` 的 `rewrites` 只配置了 `site/index.md`、`site/explore/`、`site/stage/`、`site/review/`、`site/quiz/`，没有 `site/idioms/`。本期按要求未修改 `config.mts`，因此 VitePress 按源路径输出 `/site/idioms/`。若允许改配置，增加一行即可：
   ```ts
   'site/idioms/:splat*': 'idioms/:splat*',
   ```
   卡片链接本身已是干净的 `/idioms/<word>`。
2. **未加入导航/侧边栏**：同样受 `config.mts` 禁改限制，页面只能通过 URL 或站内链接访问。
3. **数据集文本质量**：部分 `derivation` 缺开引号、含 `◇` 替换符、以“无”占位；部分 `example` 用 `～` 代指成语；个别篇名有异文（如“念如娇”）。本库一字未改，仅在正文中标注“数据集例句”。
4. **既有 20 条语义场未归一**：为不覆盖人工元数据，`semantic_field` 保留“志向/谋略/哲理/勤奋/才学/勇气/诚信/爱情·童年”，浏览页做展示归一；若后续希望 frontmatter 也统一，可单独做一次人工确认迁移。
5. **近反义覆盖有限**：298 条有至少一侧，72 条为空；关系表为人工常识，不排除个别词条在特定语境下有更细差异。
6. **学段/年级为保守占位**：小学统一 grade 6、初中统一 grade 7，`recitation: false`，不代表教材实际年级或必背要求。
7. **出处 120 字截断未实际触发**：本批最长 86 字；脚本逻辑已实现，后续新增长出处词条时会生效。
8. **中文搜索是包含匹配**：会同时命中释义、出处、近反义，因此搜“锲而不舍”返回 5 条而非 1 条；未做“词条优先”排序。
9. **每页条数不进 URL**：`size` 默认 24，切换后刷新会回到 24；筛选与页码按规范进 URL。
10. **`first`/`last` 不是统一首字母**：数据集部分值为完整音节（如 `qie`/`she`），浏览页“首字拼音”维度从 `pinyin_plain` 首字母派生，不依赖这两个字段。
11. **未做暗色主题**：站点 `appearance: false`，本期只验证三套亮色主题。
12. **才思敏捷缺失**：数据集无此词，按要求未用“才思泉涌”等相似词替代；如后续补数据可自动纳入。
13. **预览服务需在构建后重启**：VitePress preview 进程会保留启动时的资源清单；重新 build 后继续用旧进程会出现新 hash JS 404、页面只剩 SSR 骨架。最终验证时已重启 4201，页面恢复正常挂载。
